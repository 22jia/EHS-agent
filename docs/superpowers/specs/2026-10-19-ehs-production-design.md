# EHS Loop 生产化第一阶段设计

## 目标

把现有静态 MVP 变成可部署的全栈骨架：浏览器访问同一服务即可获得页面和数据接口，演示数据具备持久化能力，后续能替换为 PostgreSQL 和真实认证。

## 组件

- `dist/`：现有工作台、现场检查、整改闭环、法规与模板界面。
- `server.js`：Node 内置 HTTP 服务，负责静态文件、健康检查和资源 API。
- `data/ehs.json`：开发期仓储，保持稳定的检查、问题和法规对象结构。
- `README.md`：启动、接口和生产化边界说明。

## 数据流

页面请求 `/api/*` 获取资源；写入请求先更新内存对象，再写回 JSON 文件。生产化时只替换仓储实现，不改变页面所依赖的资源形状。

## 后续阶段

接入登录与 RBAC、组织/站点隔离、PostgreSQL、照片对象存储、审计日志、状态机约束、法规版本和部署流水线。
