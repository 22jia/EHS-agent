# 法规转检查项：写法与评审样例

以下为假设企业场景下的示范，不是已发现的问题，也不是完整企业清单。未给出的地区、生效核验、法规库 ID、现场编号等不得在运行时照抄补齐。

## 示例一：从明确条文找到应先核查的事故控制

### 原文与假设场景

《工贸企业重大事故隐患判定标准》第七条第（七）项：

> 使用非水性漆的调漆间、喷漆室未设置固定式可燃气体浓度监测报警装置或者通风设施的。

假设用户已确认：机械企业，使用非水性漆，有调漆间，下个班次准备调漆；尚未提供防护设施状态及功能验证资料。

差的写法：加强涂装安全管理，确保防火防爆设施符合要求。

### 转换项 A：调漆间固定式可燃气体监测报警装置的设置情况

| 字段 | 示例内容 |
|---|---|
| 适用条件 | 已确认使用非水性漆的调漆间；实际房间名称和编号待填 |
| 优先级及原因 | 优先核查。即将调漆，溶剂蒸气积聚可能引发火灾爆炸，须在作业前确认相应监测报警控制；尚不能认定装置缺失 |
| 检查方法 | 对照该调漆间的设备清单、布置资料和现场，核对是否设置固定式可燃气体浓度监测报警装置。便携检测仪不能作为本项固定式装置的替代证明 |
| 判定标准 | 已确认设置该类固定式装置为本项设置检查合格；确认未设置为不合格。仅拍到一个探头，不能证明布点、功能、设定值全部合规 |
| 证据 | 房间编号、现场装置照片、布置图或设备资料；记录无法确认的部分 |
| 依据关系 | 直接要求；真实运行补充法规库 ID、适用版本及上述条号、原文 |
| 整改与复查 | 确认缺失时形成任务草案，由相应专业人员确定配置与实施要求；复查安装资料及现场设置。功能、布点等另按经核验的技术依据检查 |

### 转换项 B：调漆间通风设施的设置情况

同一条款拆成另一项，核对该房间是否设置通风设施，记录设施位置与资料。现场看到普通风扇不能直接认定满足技术要求；风量、气流组织、防爆要求需要匹配技术依据后进一步核查。此项同样应在准备作业前优先确认。

原文使用“或者”，任一列明缺失情形均需按完整适用条件核对重大隐患判定。设施已经安装，不代表其运行有效；运行验证可结合第十四条及技术依据另列检查项。不能把“装了”与“有效”合成一个模糊结论。

若用户只选择“汽车制造”而未确认涂装工艺，上述条目应列为“有非水性漆调漆作业时适用”的候选，不能冒充该企业确定适用项。

## 示例二：笼统管理义务如何落到当前作业

假设输入法规确有承包单位统一协调管理及定期安全检查义务；必须引用输入中的真实条款，以下不虚构条号。

假设企业信息：承包商今天进场检维修，已提供项目与作业区域；尚无企业对该作业进行检查和问题处理的资料。

差的写法：是否建立承包商管理、培训、作业审批、隐患排查、应急救援等制度。

可用转换：**本次承包商检维修作业是否纳入企业安全检查与问题处理。**

- 现实关注：承包商作业正在发生，现场存在交叉作业和管理接口；优先确认该作业是否实际纳入企业管理，优先级为初步“优先核查”。具体伤害路径需结合已确认检维修内容补充。
- 方法：核对本次项目、作业范围及企业检查安排；查阅已有的现场检查和问题处理记录，向企业现场管理人员与承包商负责人核对实际执行。没有统一表单不直接等于未检查。
- 判定：已确认开展检查，发现的问题有处理记录或可核实的处理事实；确认未开展法规要求的检查为不合格。资料不足、尚不能确认是否执行时为待核验。
- 证据：项目、区域、检查时间、检查内容、发现问题及处理情况。涉及现场观察时记录具体位置和状态。
- 依据关系：对协调管理和检查义务的落实核查。不能仅凭该条款推出动火审批格式、隔离锁具数量或测气阈值；涉及这些时另找适用依据。
- 整改方向：补齐本次作业的现场检查与未处理问题控制；复查实际执行和问题消除，而不是只上传一份新制度。

同一管理义务的周期性制度审核仍可保留，但本次先核查正在发生的作业。不能把一份记录缺失未经完整条件核验便直接判为重大事故隐患。

## 示例三：厂务设施的检查粒度

官方机械制造评审附件 No.210 第4项涉及空压机外露旋转部位防护。它可用于校准检查对象和粒度；成为具体企业的适用依据前仍需核验本地适用性、技术要求与版本。

差的写法：空压机运行安全，设备设施完好。

候选转换：**空压机外露皮带传动部位的防护罩完整性。**

- 条件：企业确认有该类传动结构；全封闭设备不机械套用外露结构。
- 关注：接近外露运动部位可能卷入。已知护罩拆除且人员需接近运行设备时优先核查；仅知道存在空压机时，不宣称已有缺陷，优先级待暴露信息确认。
- 方法：在安全位置观察、核对设备资料；需要接近或进一步核实时先按规定停机隔离，由授权人员执行。
- 标准：需要防护的外露传动部位有与设备相符、完整固定的防护罩；缺失、脱落或损坏导致危险部位暴露为不合格。开口尺寸等参数另查适用标准。
- 证据：设备编号、传动部位、护罩全景及缺陷近照。照片不能代替联锁功能测试。
- 整改与复查：恢复防护状态，由授权人员确认后再按企业程序使用；复查原暴露部位，必要时按规定验证功能。

不能从一条“企业应加强设备管理”的一般法规义务，直接把上述技术细节和某个未经核验的尺寸写成该法规原文要求。

## 评审草案时可用的情景

| 输入情景 | 应有表现 | 不能出现 |
|---|---|---|
| 只有汽车制造行业和一般安全法规 | 从真实条文输出可支持的落实核查项，关键工艺列待确认 | 擅自确定企业有压铸、喷漆、电池作业 |
| 真实条款列出多项制度 | 按本次作业选择关键落实核查，制度义务分别保留 | 一行照抄全部制度，合并一个合格结论 |
| 已确认非水性漆调漆间即将作业 | 将报警、通风分别具体化，说明作业前优先确认的理由 | 只写完善消防管理；编造报警阈值 |
| 无现场发现、无控制状态信息 | 给待检查项及初步优先级 | 宣称企业已存在重大隐患 |
| 有护罩缺失照片及运行接近信息 | 形成具体发现、控制建议和整改草案，明确复查目标 | 仅要求加强培训后销项 |
| 只有未生效或外省法规 | 单列适用性问题或准备事项 | 包装成本企业当前必须遵守的义务 |
| 重大隐患条款含“并且” | 保留组合条件再判断法定标签 | 任一拆分检查项不合格就自动判重大隐患 |

这些是草案的验收情景，尚未构成对产品生成接口的实测结果。
